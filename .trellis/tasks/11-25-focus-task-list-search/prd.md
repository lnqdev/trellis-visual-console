# 焦点项目任务列表支持按名称与负责人搜索

## Goal

在焦点项目的任务列表（左侧 Task 树面板）提供搜索框，让用户可以按任务名称或负责人快速定位任务，无需在长长的活动/归档任务树中手动查找。

## Background

当前项目详情页的 `TaskBrowser` 左侧面板只有“活动/归档”两个集合标签，任务以父子树形式全部展示。任务数量较多时，用户只能逐个展开查找；跨项目任务中心（`TaskCenter`）虽已支持搜索，但焦点项目内的任务列表没有等价能力，需要切到任务中心再跳回。

## Requirements

- 在任务列表面板中增加搜索输入框（位于集合标签与任务树之间），输入即过滤，无需提交。
- 搜索范围与现有标签语义一致：只过滤当前选中的“活动”或“归档”集合；若归档视图处于“来自某父任务的已归档子任务”聚焦状态，则只在聚焦结果内过滤。
- 匹配规则：
  - 命中字段仅任务标题 `title`；负责人不参与关键词匹配，只通过负责人下拉筛选。
  - 去除首尾空白后按包含匹配，大小写不敏感，支持中文。
  - 不做模糊/拼音匹配，不匹配状态、阶段、包名等其他字段。
- 搜索结果保留任务树层级：
  - 只展示命中任务及其祖先链，祖先自动展开；未命中的兄弟分支与未命中子任务不显示。
  - 子任务命中时，其所在父任务作为层级上下文出现并可读，但不因“未命中”而被过滤掉。
  - 筛选态直接命中的任务展示负责人，便于确认负责人筛选结果；归档集合的“父任务”上下文展示保持现状。
  - 搜索态不展示“N 个子任务已归档”入口，避免与当前集合的搜索范围混淆。
  - 搜索态层级固定展开，不提供逐级收起；清空搜索后恢复原有树与用户此前的展开状态。
- 搜索框提供清除按钮，清空后恢复原有任务树；无匹配时展示空状态文案，而不是空白区域。
- 搜索框与负责人下拉在同一行展示（搜索框占用剩余宽度，下拉固定窄宽度），保持两者控件高度一致；窄屏下不换行。
- 负责人下拉筛选（复用现有 `Dropdown`）：
  - 下拉的可见标签隐藏但保留可访问名称。
  - 选项为「全部负责人」+ 当前可搜索集合内去重、按 `zh-CN` 排序的负责人；空负责人不生成选项。
  - 负责人筛选与搜索关键词叠加生效（AND）；任一条件激活时都采用树形结果与祖先自动展开规则。
  - 切换活动/归档集合或归档聚焦范围后，若已选负责人不在新选项中，自动重置为「全部负责人」。
  - 搜索框的清除按钮只清关键词，负责人筛选通过下拉选择「全部负责人」重置。
- 搜索状态属于 `TaskBrowser` 本地 UI 状态，不写入 URL、不影响任务详情/文档选择，也不改变当前集合标签。
- 保持现有可访问性语义：搜索输入具备可读标签，清除按钮有 `aria-label`/`title`。

## Acceptance Criteria

- [x] 在活动集合搜索任务名称片段，只剩命中的任务，点击其结果仍能正常加载任务详情。
- [ ] 子任务命中时，结果以树形展示其父级链并自动展开，父任务未命中也不会被过滤。
- [ ] 父任务命中而子任务未命中时，只显示父任务，不显示未命中的子任务与兄弟分支。
- [ ] 搜索态不展示扁平结果列表，也不展示“N 个子任务已归档”入口。
- [ ] 负责人下拉可选择某位负责人，只显示其任务及祖先链；选择「全部负责人」恢复。
- [ ] 负责人筛选与搜索关键词可叠加过滤；两者同时无结果时展示空状态。
- [ ] 切换活动/归档或归档聚焦范围后，负责人选项同步更新，失效选择自动重置。
- [ ] 搜索框与负责人下拉在同一行展示，控件高度一致；375px 下不换行、不横向溢出。
- [ ] 搜索框只匹配任务标题：用负责人名称作为关键词不再命中任务，负责人筛选只由下拉控制。
- [x] 在归档集合搜索时，结果仅来自归档集合；活动集合搜索同理。
- [x] 归档“子任务聚焦”状态下搜索，结果被限定在该父任务的已归档子任务内。
- [x] 搜索无结果时展示可读空状态；清除搜索后恢复原有任务树与展开状态。
- [x] 搜索不影响“活动/归档”标签计数与当前选中标签。
- [x] `pnpm lint`、`pnpm typecheck`、`pnpm build:web` 通过。

## Constraints

- 仅改动前端展示层（`TaskBrowser` 及其样式），不新增 Tauri Command、不改 Rust 读取契约、不新增依赖。
- 不引入路由、全局状态管理或组件库。
- 用户可见文案与注释使用中文。

## Out of Scope

- 跨项目/任务中心搜索（`TaskCenter` 已具备）。
- 按状态、阶段、包名等字段筛选。
- 拼音、模糊匹配与搜索历史。
- 搜索关键词高亮。
