# 任务文档 Markdown 预览支持文内查找

## Goal

在 Task 详情里阅读 Markdown 文档时，提供类似浏览器 `Ctrl/Cmd + F` 的文内查找能力：输入关键词即时高亮全部命中、显示命中计数，并可在命中之间上下跳转，避免用户靠肉眼在长文档里翻找。

## Background

Task 规划资料（`prd.md`、`implement.md` 等）通常较长，当前 `DocumentViewer` 只渲染正文与锚点跳转，没有检索能力。桌面端 Tauri/WKWebView 的原生查找行为不可控（不保证唤出、样式与主题不一致、无法限定在阅读区内），因此需要在应用内实现查找条。

`DocumentViewer` 同时被 `TaskBrowser` 与 `SpecBrowser` 复用，因此 Spec 文档会一并获得同样能力，行为保持一致。

## Requirements

### 打开与关闭

- Markdown 正文展示时，`Ctrl + F`（Windows/Linux）或 `Cmd + F`（macOS）打开文档内查找条，并阻止 WebView 原生查找。
- 文档工具栏提供「查找」图标按钮，作为无键盘/触屏入口，`aria-label` 为「在文档内查找」。
- `Esc` 关闭查找条并清除高亮（保留已输入关键词，便于再次打开后继续调整）。
- 关闭查找条、切换文档（含切换 Task、切换 Spec 文件）后，命中计数与当前命中位置重置，不残留旧文档状态。
- JSONL 文档不显示查找入口，快捷键也不生效。

### 匹配规则

- 输入即时生效，无需回车提交。
- 关键词去掉首尾空白后按包含匹配，大小写不敏感，支持中文。
- 只匹配正文可见文本，不匹配 Markdown 标记语法；表格、列表、标题、引用、代码块内的文本均可命中。
- 同一段落内被行内元素（如 `**加粗**`、`` `代码` ``、链接）打断的关键词仍应命中，与浏览器查找体感一致。
- 空关键词不产生任何高亮，也不展示计数。

### 高亮与跳转

- 全部命中使用统一的背景高亮；当前命中使用更强的强调样式，便于定位。
- 查找条展示「当前序号 / 总命中数」；无命中时展示「无结果」，并通过 `aria-live="polite"` 通知。
- `Enter` 或「下一个」按钮跳转到下一处命中，`Shift + Enter` 或「上一个」按钮跳转到上一处；命中之间循环，并在文档容器内滚动到可视区域（居中）。
- 关键词变化后当前命中重置为第一处，并自动滚动到该处。
- 跳转滚动只作用于文档阅读区，不改变任务/文档选择，不写入 URL。

### 布局与可访问性

- 查找条浮于文档右上角，不挤压正文；窄屏（375px）下不产生页面横向滚动。
- 查找条使用 `role="search"`，输入框具备可读 `aria-label`，按钮具备 `aria-label` / `title`，装饰图标 `aria-hidden="true"`。
- 样式使用项目 CSS 变量，浅色/深色主题下高亮与文字均可读。

## Acceptance Criteria

- [x] 在 Markdown 文档中按 `Ctrl/Cmd + F` 打开查找条并聚焦输入框，WebView 原生查找不出现。
- [x] 点击工具栏「查找」按钮同样可以打开查找条。
- [x] 输入关键词后正文命中处全部高亮，计数显示「1 / N」，当前命中样式区别明显。
- [x] `Enter` / `Shift + Enter` 与上/下一个按钮可在命中间循环跳转并滚动定位。
- [x] 跨行内元素（加粗、行内代码、链接）的关键词可以命中。
- [x] 无命中时展示「无结果」，清空关键词后高亮全部消失。
- [x] `Esc` 关闭查找条并清除高亮，再次打开保留关键词。
- [x] 切换文档或 Task 后，查找状态被重置。
- [x] JSONL 文档没有查找入口且快捷键不生效。
- [x] 375px 宽度下查找条不造成页面横向滚动。
- [x] `pnpm lint`、`pnpm typecheck`、`pnpm build:web`、`git diff --check` 通过。

## Constraints

- 只改前端展示层：`DocumentViewer` 与新增的 Markdown 查找工具模块、`styles.css`；不新增 Tauri Command，不改 Rust 读取契约。
- 不新增依赖；不引入路由、全局状态管理或组件库。
- 高亮在渲染阶段（rehype 插件）产出 `<mark>`，不直接改写 React 管理的 DOM；不启用 `rehype-raw`。
- 用户可见文案与代码注释使用中文。

## Out of Scope

- JSONL 文档的查找。
- 正则、全词匹配、区分大小写等高级选项。
- 查找历史、结果列表面板。
- 跨文档全项目搜索。

## Notes

- 轻量任务，PRD-only，不单独产出 `design.md` / `implement.md`。
