# 侧边栏折叠展开

## Goal

参考 Claude Desktop，为左侧项目导航侧边栏增加 hide/show（折叠/展开）能力，让主内容区在宽屏下可以占满窗口，同时保持随时唤回侧边栏的入口。

## Requirements

- 侧边栏展开状态下，提供一个清晰的「折叠侧边栏」按钮；折叠状态下，在主内容区左上角保留一个「展开侧边栏」按钮。
- 折叠后主内容区铺满原侧边栏腾出的横向空间，不出现布局跳动或空白列。
- 折叠状态需要持久化，重启应用 / 刷新页面后保持上次选择。
- 支持键盘快捷键 `Cmd/Ctrl + B` 切换侧边栏显示状态。
- 折叠按钮需具备可访问性：`aria-label`、`title`、可见的焦点样式；折叠时按钮使用 `aria-expanded=false`。
- 窄屏（宽度 ≤ 820px，侧边栏变为顶部横排布局）时，折叠/展开行为依然生效。
- 不改变现有侧边栏内容、项目分组、更新入口等功能。

## Acceptance Criteria

- [ ] 宽屏下点击折叠按钮，侧边栏隐藏、主内容区占满窗口；再次点击主内容区左上角按钮可恢复侧边栏。
- [ ] 折叠状态写入 localStorage，刷新或重启后状态保持。
- [ ] `Cmd + B`（macOS）与 `Ctrl + B`（其他平台）均可切换侧边栏。
- [ ] 窄屏布局下折叠/展开同样生效，且不破坏顶部分组横向滚动。
- [ ] `pnpm lint` 与 `pnpm typecheck` 通过。
- [ ] 不引入新的第三方依赖。
