# 项目移除与整体界面整合

## Goal

让用户安全移除不再需要的已登记项目，并消除 macOS 桌面窗口顶部白色原生标题栏造成的视觉割裂，使应用内容与窗口外观形成连续、统一的工作区。

## Confirmed Facts

- 用户通过桌面版截图确认，“标头”是包含 macOS 红黄绿窗口按钮和居中应用名称的白色原生窗口标题栏，不是项目内容中的 `ProjectHeader`。
- 当前 Tauri 主窗口只配置标题和尺寸，使用默认原生标题栏；见 `src-tauri/tauri.conf.json:13`。
- `ProjectHeader` 承载项目名称、路径、打开目录、刷新和焦点切换，是需要保留的业务内容；见 `src/web/components/ProjectHeader.tsx:13`、`src/web/App.tsx:119`。
- 侧边栏已经统一展示焦点、历史和不可用项目，但项目项只有选择入口，没有独立操作入口；见 `src/web/components/ProjectSidebar.tsx:118`、`src/web/components/ProjectSidebar.tsx:188`。
- 当前项目列表在选择失效时自动选择返回列表第一项，列表为空时自动打开项目发现页；见 `src/web/hooks/useProjectConsole.ts:179`。
- Core 使用固定应用数据目录中的注册表和快照保存项目集合，焦点项目另有活动 watcher；见 `crates/trellis-core/src/application/catalog.rs:51`、`crates/trellis-core/src/realtime/manager.rs:69`。
- 项目源目录必须保持只读，应用写入只允许发生在固定应用数据目录；见 `.trellis/spec/backend/index.md:31`。

## Requirements

- **R1 项目入口**：焦点、历史和不可用项目都可从侧边栏项目项右侧的垃圾桶图标移除；图标在项目项选中、鼠标悬停或键盘聚焦时可见，并提供明确的可访问名称和悬停提示。
- **R2 误操作防护**：执行移除前必须二次确认，文案明确说明只删除应用内登记和摘要快照、不删除源项目文件，且之后可以重新添加；取消确认不得调用移除 Command。
- **R3 数据与生命周期**：确认移除后删除应用注册表中的项目、对应摘要快照、临时正文读取授权和活动 watcher；不得读取后再删除、移动或写入源项目目录中的任何内容，移除状态在重启后保持。
- **R4 界面一致性**：移除后刷新项目列表和跨项目任务数据，不得继续展示已移除项目的详情、正文、任务或诊断；迟到的异步响应和 watcher 事件不得恢复过期数据。
- **R5 选择修复**：移除当前项目后自动展示剩余列表中的第一项；移除最后一个项目后进入添加项目界面；重新添加同一路径时按正常登记流程生成新快照。
- **R6 macOS 一体化窗口**：macOS 不再显示独立白色标题栏或居中窗口标题，应用深色背景延伸到窗口顶部并与侧边栏、主内容连续衔接。
- **R7 原生窗口行为**：macOS 红黄绿按钮继续支持关闭、最小化和最大化/还原，窗口保留明确可用的拖动区和系统双击行为；窗口控件不得遮挡品牌、导航、项目标题或操作区。
- **R8 业务内容保留**：保留现有项目内容区 `ProjectHeader` 及其项目名称、路径、打开目录、刷新和焦点切换能力。
- **R9 平台边界**：一体化窗口只调整 macOS；Windows 继续使用现有原生标题栏和窗口装饰，不新增自绘窗口按钮或前端窗口控制 capability。
- **R10 回归边界**：项目发现、登记、切换、实时数据、任务中心、应用更新和其他未被本任务明确修改的能力保持可用。

## Acceptance Criteria

- [x] **AC1（R1、R2）**：焦点、历史和不可用项目的侧边栏项目项均提供垃圾桶图标；鼠标和键盘均可触发，图标有可访问名称和悬停提示，且不挤压项目名称、状态、时间或诊断数量。
- [x] **AC2（R2、R3）**：取消确认后，项目登记、快照、监听和当前选择保持不变；确认后只移除应用内登记、对应摘要快照、临时授权和活动 watcher，源项目目录及 `.trellis/` 字节保持不变。
- [x] **AC3（R3）**：移除的项目在应用重启后仍不出现在项目列表和任务中心；重新添加此前移除的有效路径时正常登记并生成新快照，不恢复已删除的应用内运行状态。
- [x] **AC4（R4、R5）**：移除当前项目后不提交该项目的迟到详情或正文，自动展示剩余列表第一项；移除最后一个项目后展示添加项目界面。
- [x] **AC5（R4）**：移除任一项目后，项目列表、任务中心筛选/结果、详情、Task、Spec、Workflow 和诊断中均不残留该项目数据，迟到 watcher 消息不会重新生成快照。
- [x] **AC6（R6）**：macOS 桌面窗口不再显示截图中的白色原生标题栏和居中应用标题，深色侧边栏与主内容背景覆盖窗口顶部并连续呈现。
- [x] **AC7（R7）**：macOS 红黄绿按钮可正常关闭、最小化和最大化/还原窗口；拖动和双击拖动区行为正常。
- [x] **AC8（R7）**：在 1280x800、最小窗口 800x600 和全屏/还原状态下，窗口按钮、拖动区、品牌区域、项目标题与操作区不重叠、不裁切。
- [x] **AC9（R8）**：项目内容区现有 `ProjectHeader` 以及打开目录、刷新和焦点切换能力保持可用。
- [x] **AC10（R9）**：Windows 桌面窗口继续使用现有原生标题栏和窗口控制，安装运行行为不因 macOS 配置发生回归。
- [x] **AC11（R10）**：项目发现、登记、切换、实时数据、任务中心和应用更新等现有核心流程保持可用。

## Out of Scope

- 删除、移动或修改被查看项目的任何本地文件或 `.trellis/` 数据。
- 对项目内容增加写操作。
- 移除或重设计项目内容区的 `ProjectHeader`。
- 为 Windows 实现无边框窗口、自绘标题栏或自定义窗口控制按钮。
- 与窗口顶部一体化目标无关的页面重设计或业务功能扩展。
